# CMF_

CuriousMindsFeed video skill: Vox-style vertical explainer shorts made with Remotion, refined against studied references until they look human-made.

- `SKILL.md`: the skill (pipeline, rules, refinement loop).
- `templates/`: engine code (from the MIT-licensed `mromidev/claude-animated-shorts`, to be rewritten).
- `references/vox/`: one folder per studied video (frames, audio, transcript, notes). Start from `_TEMPLATE/`.
- `references/reports/` and `STYLE_BIBLE.md`: distilled findings (add as references are studied).
- `references/legacy-3d-style/`: the original template's reports, kept for comparison.

Keep this repo private while it contains reference material.

# tutorial/

Tutorial videos about HOW this kind of video is made (editing, motion graphics, sound design, storytelling), not the reference videos themselves.

- `tutorial/frames/<tutorial-slug>/` : frames from the tutorial (screen recordings, settings, timelines).
- `tutorial/transcripts/<tutorial-slug>.md` : full transcript, ideally word- or sentence-timed.
- Per tutorial, add a `tutorial/transcripts/<tutorial-slug>.notes.md` with the extracted rules/techniques (what to do, exact values, order of steps).

Technique notes found here get distilled into `references/reports/` and `SKILL.md`.

# random-frames/

Standalone single frames that caught your eye: a nice map, title treatment, chart, transition, colour grade. Not tied to a full video.

Naming: `random-frames/<topic>__<short-note>.jpg`, e.g. `map__dotted-route-glow.jpg`.
Optional: add a line to `random-frames/INDEX.md`: filename | source video | timestamp | why it's good.
Use for: building a visual vocabulary (maps, typography, UI, grades) the skill can pull from.
